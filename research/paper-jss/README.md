# Journal manuscript (Elsevier elsarticle) — target: Journal of Systems and Software

The long-form, Q1-journal version of the study reported in the ICEEICT 2027
conference paper (`../paper-ieee/`). The older FGCS draft in `../paper/`
predates the 2026-09-26 audit and states withdrawn claims; it is kept only as
history and must not be submitted.

## Files

- `main.tex` — preamble, front matter, back matter, appendix, references
- `sec-*.tex` — introduction, related work, system, method, results, lessons,
  threats, conclusion
- `tables/` — generated by `make_tables.py`: `tab_alltests.tex` (from
  `research/analysis/HYPOTHESIS_LEDGER.md` and the twelve records),
  `tab_level_tests.tex` and `tab_level_arms.tex` (from `RESULTS_LEVEL.md`), and
  `tab_campaigns.tex` (`tab_campaigns_base.tex`, generated by
  `../paper-ieee/make_assets.py`, plus the LEVEL row). The other tables are
  copied from `../paper-ieee/tables/`
- `figures/` — copied from `../paper-ieee/figures/` (generated by
  `make_assets.py` from the records)
- `highlights.txt` — 5 highlights, each ≤ 85 characters (`count_words.py` checks)
- `cover-letter.md` — draft; contains three author decisions to make first
- `drift_check.py` — runs the repository's withdrawn-claim patterns over this
  manuscript (3 matches, all false positives: the width experiment's
  "disagreement" metric matches the Phase 7 "DISAGREE" pattern)
- `check_log.py`, `render_pages.py`, `count_words.py` — build checks

## Build

```powershell
.\build.ps1          # make_tables.py, then pdflatex x3 -> main.pdf
python check_log.py  # overfull boxes (0 expected) and page count
```

`\blindtrue` (default) builds the anonymised review copy (system name SysX,
no authors, links or DOIs). `\blindfalse` builds the author copy.
