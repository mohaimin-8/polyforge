# Benchmarks

Raw measurement data cited by the paper. Files here are generated, never
hand-edited.

- `inference.csv` — per-request inference measurements (TTFT, tokens/sec,
  cost) across gateway backends. Generated by `go run ./cmd/llmbench`;
  methodology in [docs/INFERENCE_BENCH.md](../docs/INFERENCE_BENCH.md).
  Absent until the first live run on a machine with Ollama installed.
- HTTP load-test results for the W4/W16 RPS gates live in
  [docs/milestones](../docs/milestones) session notes; the generator is
  `cmd/loadgen`.
